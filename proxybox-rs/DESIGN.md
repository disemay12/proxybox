# DESIGN.md — proxybox

## Product
Десктопный лаунчер: запускает любое Windows-приложение через выбранный прокси,
по одной копии на процесс. Один экран, одна задача — выбрать приложение, выбрать
прокси, запустить.

## Direction
Концепт: **dispatch board**. Тёмная панель диспетчера: строки-сессии, тонкие линейки,
моноширинные адреса, всё второстепенное приглушено. Никаких карточек-плиток и градиентов.
Сигнатурная деталь: тонкая акцентная полоса слева у выбранной строки и моно-чип прокси.

Кахактеристики: точность, тишина, плотность. Анти-качества: праздничность, декор,
градиенты, «карточки-плитки».

## Шкала
- spacing: 4 / 8 / 12 / 16 / 24 / 32
- radius: 6 (контролы), 10 (панели), 999 (круглые кнопки)
- control height: 28 (sm), 34 (md), 32 (иконка-кнопка)
- row height: 66
- границы: 1px hairline; выделение — 2px accent слева + surface_active

## Компоненты
- **Title bar** — своя, 42 px: «proxybox» + счётчики слева, кнопки окна справа
  (свернуть / развернуть / закрыть), перетаскивание за всю полосу, двойной клик —
  развернуть. Системный заголовок отключён (`decorations = false`), потому что
  акцентный цвет Windows ломает тёмную канву.
- **Row (приложение)** — имя, путь (mono, muted), чип прокси (mono), кнопка ▶, кнопка ✕
  (появляется на hover/выделении). Hover → surface_hover за 120 ms, press → сдвиг содержимого
  на 1 px. Выбранная строка: surface_active + accent-полоса 2px.
- **Kill (стоп дерева)** — круг 28 px, внутри квадрат 7 px, нарисованный painter'ом
  (не глиф шрифта): hairline_strong → danger на hover за 120 ms, фон surface_hover.
  Показывается только при живых pid приложения, стоит между чипом прокси
  (правый край −128) и ✕ (−72); ▶ остаётся на −34. Tooltip «Убить все процессы приложения».
  В футере — ghost-кнопка «Стоп всё» с danger-текстом только на hover.
  На плитке превью — тот же квадрат 24×20 рядом с ✕, tooltip «Убить процесс с дочерними».
- **Proxy selector** — ComboBox на всю ширину, caption над ним; изменение назначает прокси
  выделенному приложению.
- **Buttons** — secondary (surface + hairline), primary (accent, тёмный текст), ghost (без фона).
  Press: заполнение темнее на 8%, возврат 90 ms.
- **Modal** — окно 460 px, surface, hairline, заголовок 15 semibold, ошибки danger 11.5.

## Состояния
empty (нет приложений) · selected · hover · testing (спиннер в кнопке) ·
test ok (зелёная точка + IP) · test fail (красная точка + причина) ·
add-proxy validation error (текст под полем, не только цвет).

Прокси-чип: свежая проверка → пинг в метке; три неудачи подряд → `· мёртв`
(danger, без зачёркивания и иконок); подтверждённый UDP → `· UDP` (success).
Мониторинг только назначенных прокси, раз в 30 с, в фоне.

## Motion
120 ms hover-fade, 90 ms press, 160 ms появление модала (fade + 8 px), выделение — 120 ms.
Reduced motion: без сдвигов, только мгновенная смена цвета.
